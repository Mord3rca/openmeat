#### int & uint

| name | type | comment |
|------|------|---------|
|type|byte|odd = signed|
||byte / short / int / double||

type 2, 3 if int/uint can be express as byte ([-127, 128] / [0, 255])

type 4, 5 if uint/uint can be express as short ([-32767, 32768] / [0, 65535])

type 6 if int not in previous ranges, express as int

type 7 if uint no in previous range, express as double
